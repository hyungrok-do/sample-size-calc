Study language sandbox Experimental

Open the native Lean equation compiler. This sandbox uses the earlier custom study language. Write your model and what to solve for. See the derivation, inspect its Lean proof when available, and run the calculation. Headers are optional.

Derivation uses supported symbolic rules. Exact Lean proofs currently cover rational linear and quadratic equations; general Lean proof search is not implemented.

Functions · probability · solve for
How to write “solve for” 
def objective (x : Real) : Real := x^2 + 2*x

solve for x : Real in [0, 10]
where objective(x) = 8

Use Nat for integer searches, Real for equation roots, or Grid with step for a finite grid. To calculate a value directly, write evaluate power(63).

Write probability(event) around a Boolean event generated by your random model. The compiler derives supported Gaussian probabilities analytically and otherwise uses simulation. Before the query, set its precision with simulation { replicates := 20000, seed := 42, confidence := 0.95 }.

Supported: typed functions, let, if, arithmetic, arrays, sample(n, fun i => ...), map, summary statistics, distributions, and numerical integration. This is a Lean-style study language with its own solve syntax, not the full Lean language or proof kernel.

For a normal study, sd is the common known standard deviation and counts are per arm. For an influence-function study, variance is the variance coefficient per independent participant or cluster for the planned estimator.

      The downloaded C++ contains your compiled expression and builds independently with a C++17 compiler. Browser Solve executes the typed expression plan in the C++/WebAssembly runtime.

      Compilation and proof checks

      The compiler checks the supported syntax, types, and numerical domains. For supported algebraic equations it also generates a separate Lean proof. The browser exports that proof; the native check runs Lean’s kernel. The earlier declaration templates support their own native Lean check.

      Generate, compile, and run a native executable from this study:

      python scripts/compile_study.py study.study --cpp study.cpp --run

      Numerical evaluation uses ordinary floating-point arithmetic.
