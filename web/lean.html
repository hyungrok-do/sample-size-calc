The browser includes Lean, Init, Std and SSC. SSC provides composable probability laws, numerical distribution functions, seeded simulation, design search and a proof reporter. Statistical models and test equations are defined in your source. Mathlib is not bundled.

A Specification defines the null law, alternative law and rejection event for any design type. Automatic evaluation tries finite rational enumeration, then supported numerical integration, then samples the same law and evaluates the same event. It never replaces a failed proof with simulation.

The observation examples use SSC.Derivation. Its finite-program compiler returns a distribution with a proof that every expectation agrees with the observation program. Equal intermediate states can be combined without changing probabilities. If its work budget is exhausted, evaluation samples the original program. Continuous distribution derivations are not yet provided.

Search covers the supplied ordered candidates. Monte Carlo intervals can leave candidates unresolved. When a type-I error constraint is omitted, the null rejection rate is reported but does not constrain the search.

Lean's kernel checks theorem proofs. Hypotheses remain conditions of those theorems. The report shows their actual proof terms, dependencies and source tactic goals.

Evaluation output is separate from proof. A numerical value is certified only by an explicit theorem about it. Approximation error bounds and links from a probability model to a supplied formula must also be proved or stated as hypotheses.

Include import SSC in a complete Lean module. A failed tactic displays Lean's remaining goals. An unrestricted automatic mathematical solver is not provided.
