Specify the study, estimand, covariance or influence function, and planned analysis. Derive power and find the sample size that meets your criterion.

Checking the native compiler…

This hosted page is an editor. To compile studies, start the local service from a checkout with Python 3, a C++17 compiler, and the pinned Lean toolchain:

cd lean
lake exe cache get
lake build DesignCompiler.Planning.Command
cd ..
python scripts/serve_lean.py

Then open the local Lean editor. Run code you trust: Lean modules can perform IO.

For browser access without a local installation, the repository includes a hosted compiler deployment. GitHub Pages alone serves the editor.

1 Lean source

Study language and supported inference 
open DesignCompiler.Planning
-- Define study : Study with a covariance or influence model.
solve sample_size design using study
solve power planned_power using study at 100
solve effect detectable_effect using study at 100

Ordinary Lean functions and expressions can construct the covariance, allocation, and influence variance. The Gaussian contrast model propagates an arbitrary covariance matrix; it does not select a canned test from the example name.

Known-covariance Gaussian contrasts use a z test. AIPW/TMLE and custom influence-function designs use asymptotic Wald inference. Estimated-covariance t/F inference and native Monte Carlo study compilation are not implemented in this route.

For detectable effects the variance is held fixed. ATE effect queries require changing the planning strata explicitly, because the variance can change with the effect.

The service supplies the import. Lean checks exact effect and variance arithmetic; numerical power and integer search run in generated C++.
