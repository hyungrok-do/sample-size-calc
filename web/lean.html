1 Study in Lean

NormalInput · InfluenceInput
Supported Lean syntax

Define study : NormalInput or study : InfluenceInput. Use numbers, decimals, fractions, quoted strings, and comments. The browser compiles this declaration subset. Other Lean programs and proof tactics require a native Lean environment.

For a normal study, sd is the common known standard deviation and counts are per arm. For an influence-function study, variance is the variance coefficient per independent participant or cluster for the planned estimator.

2 Compile

Generated C++

Solve runs the calculation plan in the compiled C++/WebAssembly engine. The downloaded source builds independently with a C++17 compiler.

Compilation and proof checks

The browser checks the supported syntax and numerical parameters. It does not run Lean’s proof kernel. The repository includes Lean proofs for the normal rejection formula, algebraic lowering, and finite-search properties.

Check this source with native Lean and compare the two exported plans:

python scripts/compile_lean.py study.lean --cpp study.cpp

Numerical evaluation uses ordinary floating-point arithmetic.
