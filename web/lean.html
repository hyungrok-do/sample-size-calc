Study language and supported inference 
open DesignCompiler.Planning
-- Define study : Study with a covariance or influence model.
solve sample_size design using study
solve power planned_power using study at 100
solve effect detectable_effect using study at 100

Ordinary Lean functions and expressions can construct the covariance, allocation, and influence variance. The Gaussian contrast model propagates an arbitrary covariance matrix; it does not select a canned test from the example name.

Known-covariance Gaussian contrasts use a z test. AIPW/TMLE and custom influence-function designs use asymptotic Wald inference. Estimated-covariance t/F inference and Monte Carlo study compilation are not implemented in this route.

For detectable effects the variance is held fixed. ATE effect queries require changing the planning strata explicitly, because the variance can change with the effect.

The browser supplies the statistical compiler module. The actual Lean kernel checks exact effect and variance arithmetic; numerical power and integer search run in the C++ WebAssembly backend. No local installation or compiler server is needed.

This browser package includes Lean's core library and the statistical study language. The separate Mathlib probability audit and general real-equation solver remain native tools; they are not loaded into this browser package.
