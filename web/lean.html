Define a function in Lean. Ask for its solution. Get a derivation and a theorem checked by Lean’s kernel.

The solve command searches for a proof using composable theorems. Add your own with @[equation_rule].

Checking the native compiler…

This hosted page is an editor. To compile Lean, start the local service from a checkout with Python 3 and the pinned Lean toolchain:

cd lean
lake exe cache get
lake build DesignCompiler.Solve
cd ..
python scripts/serve_lean.py

Then open the local Lean editor. Run code you trust: Lean modules can perform IO.

1 Lean source

Lean syntax and extending the solver 
noncomputable def response (x : ℝ) : ℝ :=
  Real.exp (2*x + 1)

solve answer for x : ℝ where response x = 5
#check answer

Use ordinary Lean definitions, notation, namespaces, and section variables. Function application is response x. Real-valued mathematical functions often need noncomputable def.

The service supplies import DesignCompiler.Solve. You can add imports for other installed modules. The compiler uses Lean’s parser, elaborator, expression representation, and kernel.

Prove an equality or equivalence and mark it @[equation_rule] to make it available to proof search. Assumptions are retained in the theorem; conditions and multiple roots are not silently dropped.

Search is bounded. “Unresolved” means the compiler did not find an explicit solution with its current rules and budget.
