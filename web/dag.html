Data generating process

Drag nodes to arrange. Select a variable to edit. Use its + port, then choose a destination, to draw an arrow. Keyboard: Tab, Enter, arrow keys. The controls below also connect nodes.

The model behind your graph

Each variable has its own conditional distribution. Incoming arrows add parent terms to its predictor on the distribution’s displayed scale. The equations below show exactly how data are generated.

    Assumptions and scope
    • A variable has a type and a distribution. Names such as treatment, mediator, or outcome are optional labels; they impose no structural restrictions. Any directed acyclic graph is allowed.
    • Continuous distributions: Normal, Uniform, Log-normal, Gamma. Binary: Bernoulli. Count: Poisson. Survival time: Weibull or Exponential, with a proportional hazards predictor.
    • Arrows and parent interactions define the conditional model in the variables’ original units. A dependency arrow needs a numerical effect; the graph alone does not determine a joint distribution.
    • Survival variables generate latent event times. Optionally specify an administrative cutoff or another variable as the censoring time to also obtain observed follow-up and an event indicator. Shared parents can induce dependent event and censoring times.
    • Exogenous draws are independent across variables and rows. Dependence arises through the graph. Variable types do not determine an analysis or adjustment set.
    • All example values are editable assumptions. Power uses the saved estimand’s compatible analysis and rejection rule. A numerical planning alternative calibrates a selected DGP arrow before studies are simulated.
    • Models stay in this browser and can be exported as JSON. Generated data can be downloaded as CSV.
